# Passive-first hook calibration v2 — proposed protocol

This file is written before v2 parameter fitting. `hook_flexion_02_treadmill.parquet` is reserved and must not be loaded by the fitting CLI. All previously inspected hook01 recordings are development data, including their former test animals.

## Proposed development experiment

1. Deterministically partition numerical animal IDs into three development folds (seed 20260913), conservatively sharing IDs across development files. Hold out each fold in turn. All preprocessing/calibration and parameter selection for a fold exclude its animals across passive hook01, active hook01 and 9A recordings.
2. Within each outer training partition, choose a hook velocity response and calcium decay using leave-one-animal-out passive prediction. The prespecified candidate responses are binary flexion below −20 or −100 degrees/s, or saturating rectified flexion speed with scales 50 or 200 degrees/s. Calcium rise is fixed at .03 s; decay candidates are .15, .30 and .60 s. Each candidate fits only a global nonnegative amplitude and offset on inner training animals. No test target normalization is allowed.
3. Independently select a behavioral-drive time constant (.03, .10, .30 or 1 s) by leave-one-animal-out prediction of measured 9A calcium from observed `L1_move`, with a fixed .03/.30 s calcium observation kernel and training-only amplitude/offset. This is a **calcium-level observational drive constraint**, not recovered 9A spikes or an identified causal synapse. Compare with a training-mean constant and report whether dynamics are informative.
4. Freeze the passive-selected response/kernel and 9A-selected time constant. Select hook suppression beta (0, .5, 2 or 8) by inner leave-one-animal-out active hook01 prediction. Fit one active-training-only global amplitude/offset, common across held-out animals, to accommodate acquisition scale; it is not a transferable synaptic gain. The velocity and calcium dynamics remain passive-derived. Report the separately fitted passive amplitude/offset to expose scale differences.
5. Fair controls: the same passive-selected response with beta=0 and an independently fitted active-training amplitude/offset; a training-mean constant; and a compact v1-style active-only candidate family (binary thresholds −20/−50/−100, gate times .03/.30, beta 0/2/10), each selected only by inner animal cross-validation.
6. Aggregate outer-fold predictions with equal animal weighting. Report per-animal MSE, RMSE, correlation, and active/not-actively-moving errors. Report paired animal-bootstrap uncertainty and model selection stability. Former v1 test animals are explicitly no longer fresh tests.
7. After reviewing development results, freeze a configuration and artifact. The parent agent must explicitly authorize a **single reserved hook02 evaluation** after verifying its untouched status. The development CLI cannot read that file. A failure remains a failure; the reserved set cannot become another tuning set.

All native frames update filters; score every third `analyze=1`, finite target frame. Reset at animal/trial/ROI boundaries and timing gaps. Do not use supplied `predicted_calcium`. Source hashes, protocol hash, folds, candidate grids, scale assumptions and software hashes accompany results. The calcium kernel is a causal discrete cascade approximating a difference-of-exponentials kernel; no receptor parameters are inferred. No runtime integration occurs in this experiment.

Normalization provenance is under independent audit. The experiment must pause or narrow its interpretation if source normalizations invalidate quantitative cross-dataset amplitudes. No per-held-out-animal normalization or fitted intercept is permitted.

## Approved additions before fitting

The independent audit found that stored active calcium is a per-trial baseline z-score of GCaMP/tdTomato ratio, upsampled to 300 Hz and smoothed over 0.2 s. Figure scripts additionally normalize each driver dataset by its maximum; **that figure normalization is not reproduced here**. Passive preparations start from a different fluorescence observation (ΔF/F); absolute passive-to-active gain cannot be assumed. Consequently there are two frozen training-only observation heads: a passive amplitude/offset fitted only to old passive animals, and an active amplitude/offset fitted only to old active animals. There is no head refit on either final cohort.

The published model applies a unit-sum causal double-exponential kernel without another 0.2 s smoothing pass. The raw moving-average centering is undocumented. V2 adds no new smoothing pass. Its limited calcium-decay grid is an observation-model sensitivity, not receptor kinetics. The published kernel itself was historically tuned using Mamiya2018 data; the reserved Mamiya animals are untouched by this new fitting but are not wholly independent of the literature's historical model design.

Reserve `hook_flexion_01_magnet_Mamiya2018.parquet` animals 2–14 for final passive transfer; animal 1 was previously exposed and is excluded. Never use any Mamiya data for v2 training. Passive final predictions use the passive head with gate off. Compare against the passive training-mean constant and a fixed published-kernel baseline (0.03/0.30 s; velocity response selected on passive development animals). Passing passive transfer can validate only sensory observation prediction, not suppression, because the gate is off.

For active final evaluation, freeze the strongest of nongated, constant and v1-style controls based on development outer-fold MSE before seeing hook02. The hook02 driver JR252 differs from hook01 R21D12, so the reserved cohort contains distinct animals despite overlapping numerical IDs. Cross-driver amplitude transfer is still an explicit generalization challenge, not an assumed equivalence.
